## Manualne potwierdzenia i ograniczenia

Użytkownik potwierdził aktualizację i import statystyk bez zarzutu, bez
podania ścieżki/urządzenia, oraz zaakceptował odsłuch prototypów trzech barw.
Zgoda na publikację nie jest nowym wynikiem testu. Nie dopisujemy odbioru
finalnego APK ani całego M6. Historyczny odbiór RC2/A56 pozostaje osobnym
zapisem w [M6](M6-ACCEPTANCE.md).

W tym etapie nie wykonywano operacji na telefonach, fizycznego audio ani
wibracji. Fizyczne jitter i latencja pozostają **niezmierzone**. Pełny dysk
może uniemożliwić utrwalenie najnowszych danych.

Pełny rejestrator DEV pozostaje wyłączony po FAIL API26 +14,05%, przy
niezmienionym progu +10%. Nie jest zaliczony ani wymagany dla PROD.
[Analiza DEV](V1.1-DEV-COST-ANALYSIS.md),
[pochodzenie brzmień](../assets/samples/PROVENANCE.md).
