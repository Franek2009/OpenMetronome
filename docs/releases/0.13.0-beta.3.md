# OpenMetronome 0.13.0-beta.3 — odzyskiwanie przerwanego przywracania

Przywracanie kopii `.ombak` ma trwały dziennik. Jeśli proces zostanie przerwany,
przy następnym uruchomieniu aplikacja odzyska cały poprzedni zestaw danych albo
dokończy cały zatwierdzony zestaw, zanim udostępni Start i edycję. Nieczytelny
dziennik blokuje zmiany i zachowuje materiały odzyskiwania.

Poprawiono kończenie edycji liczb treningu i nazw presetów przyciskiem klawiatury
„Gotowe”, także na Androidzie 8. Format kopii `.ombak` v1 i schemat bazy 2
pozostają zgodne z poprzednimi wydaniami.

## Weryfikacja

136 testów JVM PASS. Pełne ciche zestawy na API 26, API 35 i Samsungu SM-A145R:
na każdym **58 PASS, 6 pominiętych prób audio**, zero innych pominięć i błędów.
CI obejmuje również zachowanie ustawień, presetów, historii, statystyk i
sampli po aktualizacji beta.2→beta.3 na API 26 i 35. Testy aktualizacji używają
kopii APK z jednorazowym podpisem testowym; oficjalny podpis i smoke są osobnymi
bramkami procesu wydawniczego.

Testy odzyskiwania rzeczywiście przerywają osobny proces na izolowanych danych,
także podczas samego odzyskiwania. Nie są sprzętowym testem odcięcia zasilania.
Nie wykonywano audio, wibracji ani sesji 30-minutowej. Lenovo pominięte zgodnie
z decyzją użytkownika. Pełny odbiór audio, M6 i gotowość 1.0 pozostają otwarte.
Kopie `.ombak` nie są szyfrowane.

Android 8.0+, versionCode 15. Oficjalny APK używa dotychczasowego certyfikatu.
Instalacji roboczej z innym podpisem nie aktualizuje się oficjalnym APK przez
zwykłe `install -r`; nie usuwaj aplikacji ani jej danych w celu obejścia odmowy.
