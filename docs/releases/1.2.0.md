# OpenMetronome 1.2.0

Oficjalnie podpisany OpenMetronome **1.2.0**, versionCode **21**.
Pakiet `org.openmetronome`, Android 8+, dotychczasowy certyfikat PROD.

## Nowości

- Mini Metronom: BPM i Start/Stop na pulpicie; BPM otwiera aplikację.
- Sterowanie: procenty 100/75/50/25%, BPM wynikowe, liczbowy podgląd bazy;
  po powiększeniu −1/+1. Ręczna zmiana bazy wyłącza rampę jak w aplikacji.
- Statystyki: zapisany czas dzisiaj, seria i aktywne dni tygodnia.
- Minimalistyczne podpisy, instrukcje w README i pełne opisy dla TalkBack.
- Aktualne zrzuty aplikacji i renderowane podglądy widgetów w README.

Widgety współdzielą sesję istniejącej usługi. Bez animowania pulsu i bez
samoczynnego Start przy odświeżeniu. Bez zmian silnika PCM, brzmień,
Room, formatu `.ombak`, identyfikatorów danych i konfiguracji podpisu.

## Odbiór i ograniczenia

Użytkownik zaakceptował wygląd podglądów. Praktyczny odbiór widgetów w launcherze
Samsunga pozostaje niepotwierdzony. Nie wykonywano operacji na telefonach.
To nie jest nowy manualny PASS M6 ani pomiar fizycznego jittera lub latencji.

Rozmiary zależą od launchera. Po zabiciu procesu ostatni widok może pozostać
do odświeżenia. Statystyki pokazują zapisany czas, bez sekundnika niezapisanej
części. Pełny dysk może uniemożliwić zapis najnowszych danych.
Pełny rejestrator DEV pozostaje wyłączony; kwalifikacja narzutu NOT RUN w tej
regresji, wcześniejszy FAIL API26 nie jest przedstawiany jako PASS.
