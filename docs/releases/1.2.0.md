# OpenMetronome 1.2.0 — szkic przed podpisaniem

Przygotowywane wydanie zwykłej aplikacji: `org.openmetronome`,
versionName **1.2.0**, versionCode **21**, Android 8+.
Nie utworzono jeszcze tagu, oficjalnie podpisanego APK ani publicznego wydania 1.2.0.

## Zmiany względem 1.1.0

- Mini Metronom: BPM i Start/Stop bez otwierania aplikacji.
- Sterowanie: BPM wynikowe, procenty 100/75/50/25%, liczbowy podgląd bazy;
  po powiększeniu także −1/+1. Ręczna zmiana bazy wyłącza rampę jak w aplikacji.
- Statystyki: zapisany czas dzisiaj, seria i aktywne dni tygodnia.
- Minimalistyczne podpisy; instrukcje w README, pełne opisy dla TalkBack.
- Aktualne zrzuty aplikacji i renderowane podglądy widgetów w README.

Widgety współdzielą sesję istniejącej usługi. Nie animują pulsu i nie uruchamiają
odtwarzania przez samo odświeżenie. Bez zmian silnika PCM, brzmień, Room,
formatu `.ombak` i konfiguracji podpisu. Dane i identyfikatory są zachowane.

## Weryfikacja przed publikacją

- CI dokładnego końcowego PR i scalenia main: zaliczyć przed tagowaniem.
- Oficjalny podpis, SHA-256 APK, metadane i manifest: NOT RUN przed podpisaniem.
- Oryginalny oficjalny 1.1.0 → oficjalny 1.2.0 na API26/35: NOT RUN.
  Sprawdzić ustawienia, presety, historię, statystyki i dokładne bajty własnych
  sampli, bez przepodpisywania APK i bez kasowania danych.
- Odbiór widgetów w launcherze Samsunga: niepotwierdzony. Akceptacja wyglądu
  podglądów nie jest potwierdzeniem testu fizycznego urządzenia.

Przed publikacją zastąpić powyższe statusy rzeczywistymi wynikami i dodać
sumę oficjalnego APK. Nie wpisywać sumy APK debug jako sumy oficjalnego wydania.
Dotychczasowy certyfikat PROD SHA-256:
`563cd960efc3fc5b483ceae4b96e66728af9e2bb0c52d6162fe37cded72ac4a2`.

## Ograniczenia

Rozmiary widgetów zależą od launchera. Po zabiciu procesu ostatni widok może
pozostać do odświeżenia; nie zapisujemy flagi Gra i nie wznawiamy automatycznie
sesji. Statystyki pokazują zapisany czas, bez sekundnika niezapisanej części.
Fizyczny jitter i latencja pozostają niezmierzone. Pełny rejestrator DEV
pozostaje wyłączony; brak nowego APK DEV w planowanym zestawie PROD.
