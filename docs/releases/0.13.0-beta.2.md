# OpenMetronome 0.13.0-beta.2 — bezpieczniejsze kopie zapasowe

Eksport i przywracanie `.ombak` wymagają ręcznego Stop oraz zakończenia
zapisu sesji. Podczas operacji Start i zmiany danych są blokowane.
Eksport uwzględnia wcześniejsze zapisy ustawień i sprawdza archiwum przed
otwarciem pliku docelowego. Kopie v1 z 0.13.0-beta.1 pozostają obsługiwane.

Przywracanie zachowuje poprzednie dane do cofnięcia obsługiwanych błędów
bazy, preferencji lub plików. Awaria samego cofania wyświetla ostrzeżenie
o niepełnym stanie i zachowuje prywatne materiały odzyskiwania.
Obrót ekranu zachowuje oczekujące potwierdzenie. Uszkodzony lub niedostępny
plik i anulowanie wyboru nie powinny zmieniać danych. Niepełny eksport
jest jawnie zgłaszany.

Nie ma jeszcze gwarancji odzyskiwania po zabiciu procesu, restarcie urządzenia
lub utracie zasilania podczas przywracania. Kopia nie jest szyfrowana.
Pełny odbiór audio, długie sesje i M6/1.0 pozostają otwarte.

Android 8.0+, versionCode 14. Oficjalne wydanie używa dotychczasowego certyfikatu;
nie odinstalowuj aplikacji debug o innym podpisie w celu obejścia odmowy aktualizacji.

[Wyniki i ograniczenia](https://github.com/Franek2009/OpenMetronome/blob/v0.13.0-beta.2/docs/V0.13-BETA2-VALIDATION.md).

## Weryfikacja i zakres odbioru

131 testów JVM PASS, Lint debug/release bez błędów. Samsung SM-A145R i świeży
emulator API 35: na każdym **53 PASS, 6 pominiętych prób audio**, zero innych
pominięć i błędów. Obejmuje pełny backup, kontrolowane błędy i cofanie,
ponowne otwarcie danych oraz rzeczywisty systemowy picker na syntetycznym
dostawcy dokumentów. Nie uruchamiano audio ani wibracji.

**Końcowy odbiór Lenovo pominięto na polecenie użytkownika.** Wcześniejsza
instrumentacja miała błąd automatyzacji UI oraz niekompletny raport przy
zrywaniu USB. Nie deklarujemy zaliczenia testów tej wersji na tablecie.
