# OpenMetronome 1.0.0-rc.1 — propozycja

Kandydat do pierwszego stabilnego wydania, bez nowych funkcji. Nieopublikowany.

- Naprawiona rezerwacja Start po błędzie uruchomienia foreground.
- Końcowy zapis sesji przetrwa zniszczenie usługi; zaległe zapisy są ponawiane
  i odzyskiwane po restarcie z prywatnego dziennika.
- Eksport historii i kopii nie zgłasza sukcesu, jeśli pozostał niezapisany stan.
- Starsze kopie `.ombak` v1 pozostają czytelne; statystyki dzienne i checkpointy
  są odbudowywane z sesji, bez odrzucania historycznych rozbieżności.

Android 8+, identyfikator `org.openmetronome`, versionCode 16. Zachowany
oficjalny certyfikat, schemat bazy i format kopii. Nie odinstalowuj aplikacji,
aby obejść niezgodny podpis; zachowaj dane i wyjaśnij pochodzenie starszego APK.

Przy jednoczesnej niemożności zapisania bazy i dziennika odzyskiwania najnowsze
dane pozostają w pamięci; restart przed udanym ponowieniem może je utracić.
Pomiary fizycznej precyzji audio oraz pełny odbiór M6 pozostają otwarte.

[Wyniki, ograniczenia i bramki](../V1.0-RC1-VALIDATION.md).
Publikacja wymaga osobnej zgody i weryfikacji podpisanego artefaktu.
