# OpenMetronome 1.1.0

**Oficjalnie podpisane wydanie stabilne OpenMetronome 1.1.0.**
PROD `org.openmetronome`, versionName **1.1.0**, versionCode **20**.
To stabilne wydanie zwykłej aplikacji, bez nowego APK DEV.

## Zmiany względem 1.0.0

- Pełny ekran z dużym BPM, pulsem i taktem, blokadą dotyku z dostępnym Stop,
  utrzymywaniem ekranu i ograniczeniem migania, bez restartu sesji.
- Procenty 100/75/50/25% niezależne od bazy 20–300 BPM; wynik 5–300 BPM.
  Rampa zmienia bazę. Zmiana tempa od taktu albo następnego możliwego pulsu.
- Odliczanie 0/1/2 takty poza czasem praktyki, metra 5/4, 7/4, 5/8 i 7/8,
  grupowanie 5/8 i 7/8. W 6/8 BPM nadal oznacza ósemki.
- Statystyki 2.0: cały czas dzisiaj, podsumowanie, historia, analiza, filtry
  i progi 20 s/sesję oraz 5 min/aktywny dzień. Krótkie sesje pozostają w historii.
- Trzy nowe barwy: Naturalny, Suchy, Naturalny niski, z osobnymi akcentami.
  Dotychczasowe sześć brzmień zachowane. Krótsze podpisy UI, bez redesignu.

## Dane i aktualizacja

Room 3 z migracją z 1.0; import kopii `.ombak` v1/v2, domyślny eksport v2.
Eksport zgodny v1 ostrzega o pominięciach i odrzuca nowe metra lub barwy,
których 1.0 nie odczyta. Nieznany przebieg starych sesji nie jest zerem.
Nie zakładamy możliwości cofnięcia instalacji do niższego versionCode.
Nie odinstalowuj aplikacji ani nie czyść danych przy niezgodności podpisu.

## Odbiór i ograniczenia

Manualnie użytkownik potwierdził prawidłową aktualizację i import statystyk
oraz zaakceptował odsłuch prototypów trzech barw. Nie jest to pełny odbiór
finalnego APK 1.1 ani wszystkich scenariuszy M6. Odbiór finalnego APK pozostaje
otwarty. Fizyczne jitter i latencja nie zostały zmierzone; test PCM nie jest
pomiarem głośnika. Pełny dysk może uniemożliwić utrwalenie najnowszych danych.

Pełny rejestrator DEV pozostaje wyłączony po FAIL narzutu API26 (+14,05%,
próg +10%). Nie jest zaliczony ani wymagany dla PROD. Wydanie nie zawiera APK DEV.
Dodatkowe próbki VCSL oczekują na wybór; brak osobnej barwy Drewniany nie blokuje 1.1.
