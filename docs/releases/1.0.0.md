# OpenMetronome 1.0.0 — przygotowanie pierwszego stabilnego wydania

**Jeszcze nieopublikowane.** Opis przygotowany do przyszłego procesu
wydawniczego; nie oznacza ukończenia M6 ani dopuszczenia publikacji.

- Metronom offline, trening ciszy i zmian tempa, presety i historia ćwiczeń.
- Statystyki, CSV i kopie `.ombak` obejmujące także własne sample.
- Niezawodniejsze kończenie sesji, ponawianie zapisów i odzyskiwanie
  utrwalonych sesji po restarcie; zgodność starszych `.ombak` v1.
- Oficjalne logo użytkownika i sześć dotychczasowych barw. „Drewniany”
  pozostaje poza 1.0.0, planowany na 1.0.1.

Względem RC2 zmieniają się wyłącznie metadane: **1.0.0 / versionCode 18**.
Pakiet `org.openmetronome`, Android 8+, Room 2, format kopii i konfiguracja
dotychczasowego oficjalnego certyfikatu pozostają bez zmian.

Użytkownik ręcznie potwierdził na A56 aktualizację i uruchomienie RC2,
poprawne logo i ogólne działanie bez zauważonych problemów. Nie potwierdził
wszystkich scenariuszy M6, wibracji ani fizycznych pomiarów audio.

Nie ma jeszcze oficjalnie podpisanego APK 1.0.0, jego SHA-256 ani wyników
oficjalny→oficjalny upgrade do 1.0. Po osobnym zatwierdzeniu należy je
uzupełnić dla dokładnego nowego artefaktu, nie kopiować wyników RC2 jako 1.0.

Ograniczenia: fizyczny jitter i latencja niezmierzone; brak gwarancji wszystkich
urządzeń i tras audio. Pełny dysk odrzucający bazę i dziennik może pozostawić
najnowszy stan tylko w pamięci. Przerwanie procesu może utracić fragment po
ostatnim trwałym checkpointcie. Test procesu nie zastępuje odcięcia zasilania.
Niezgodności podpisu nie obchodzimy odinstalowaniem ani czyszczeniem danych.

[Raport regresji i bramki](https://github.com/Franek2009/OpenMetronome/blob/release/1.0.0/docs/V1.0-VALIDATION.md).
Przed publikacją należy zamienić ten adres na zatwierdzony tag/SHA.
Tag, podpisanie oraz publikacja stable wymagają osobnych decyzji użytkownika.
