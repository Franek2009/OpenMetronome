# OpenMetronome 1.0.0-rc.2 — kandydat nieopublikowany

RC2 zawiera zaakceptowane nowe logo. Nie dodaje funkcji ani brzmień.
To przyszły **Release Candidate (Prerelease)**, nie stabilne 1.0.0.
Tag, oficjalny podpisany draft i publikacja wymagają osobnego zatwierdzenia.

- Oficjalne logo użytkownika: ikony adaptacyjne z jednolitym zielonym tłem,
  monochromatyczne Androida 13+ oraz klasyczne PNG. Geometria pozostaje
  dokładnie w zaakceptowanej postaci.
- Sześć dotychczasowych barw i ich identyfikatory pozostają bez zmian.
  Dodatkowy „Drewniany” odłożony do 1.0.1, poza bramkami RC2 i 1.0.0.
- Zachowane poprawki zapisu sesji, odzyskiwania i `.ombak` v1 z RC1.

Android 8+, `org.openmetronome`, versionName 1.0.0-rc.2, versionCode 17.
Konfiguracja dotychczasowego certyfikatu, Room 2 i format `.ombak` v1 bez zmian.
Przygotowanie PR nie zmienia opublikowanego RC1 ani jego tagu/APK.

Oficjalny podpisany RC2, jego SHA-256 i aktualizacja oficjalny→oficjalny:
**jeszcze niewykonane**. Zwykły CI sprawdza aktualizację kopii z testowym
podpisem, nie podpis produkcyjny. Nie odinstalowuj aplikacji ani nie usuwaj
jej danych przy błędzie niezgodności podpisów.

Praktyczny odbiór RC2 i M6 pozostają otwarte. Fizyczny jitter i latencja są
niezmierzone; testy ciche nie zastępują odsłuchu. Gdy dysk odrzuca zarówno
bazę, jak i dziennik, najnowsze dane mogą pozostać tylko w pamięci.
Wcześniejsze próby RC1 i potwierdzenie aktualizacji na A56 nie są odbiorem RC2.
