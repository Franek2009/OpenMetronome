# OpenMetronome 1.0.0-rc.2 — szkic, nieopublikowany

Ten plik jest przygotowaniem opisu, **nie potwierdzeniem gotowości RC2**.
Przed procesem wydawniczym uzupełnić wyniki dokładnego artefaktu.

- Nowe oficjalne logo użytkownika: ikony adaptacyjne, monochromatyczne
  Androida 13+ i klasyczne PNG. Wygląd zaakceptowany; PR #5 scalony.
- Bez dodatkowych brzmień i zmian funkcjonalnych; sześć dotychczasowych
  barw pozostaje bez zmian. „Drewniany” odłożony do 1.0.1.
- Zachowane poprawki zapisu sesji, odzyskiwania i `.ombak` v1 z RC1.

Planowane: Android 8+, `org.openmetronome`, versionName 1.0.0-rc.2,
versionCode 17 po osobnym zatwierdzeniu metadanych i sprawdzeniu dostępności.
Dotychczasowy certyfikat i Room 2 bez zmian. Brak migracji danych na telefonach.

Podpisany RC2, jego SHA-256 i aktualizacja oficjalny→oficjalny: **niewykonane**.
Nie instalować nieoficjalnie podpisanej kompilacji w miejsce oficjalnej;
nie odinstalowywać aplikacji ani nie usuwać danych przy błędzie podpisu.

RC pozostaje Prerelease; praktyczny odbiór tej wersji i M6 nie są zakończone.
Jitter/latencja fizycznego wyjścia niezmierzone; pełny dysk może uniemożliwić
utrwalenie najnowszych danych. Wcześniejsze próby RC1 nie są odbiorem RC2.
