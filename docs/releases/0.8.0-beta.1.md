# OpenMetronome 0.8.0-beta.1

Testowe wydanie darmowego metronomu Android, offline, bez reklam i kont.
Wymagany Android 8.0 lub nowszy. Pobierz **OpenMetronome-0.8.0-beta.1.apk**,
nie archiwum Source code. Telefon i tablet są obsługiwane w obu orientacjach.

Tempo 20–300 BPM, tap tempo, metrum i podziały, trening ciszy, progresje,
rampy tempa, trzy brzmienia, presety i lokalne statystyki z eksportem CSV.
Nowy, krótszy pasek nawigacji nie wyświetla nazwy aplikacji.

APK ma stały podpis wydawniczy. SHA256SUMS pozwala sprawdzić integralność
pliku, SIGNING-CERT-SHA256.txt zawiera odcisk certyfikatu aktualizacji.
**APK debug z wcześniejszych prac ma inny podpis:** nie odinstalowuj go,
jeżeli chcesz zachować dane. CSV nie pozwala przywrócić całej bazy.

To beta, nie ukończona stabilizacja 1.0. Odbiór długiej sesji i fizycznej
precyzji wyjścia audio pozostaje otwarty. W 6/8 BPM oznacza sześć ósemek
na takt. Szczegóły testów: [raport](https://github.com/Franek2009/OpenMetronome/blob/main/docs/V0.8-VALIDATION.md).
