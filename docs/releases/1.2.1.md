# OpenMetronome 1.2.1

Wersja stabilizacyjna, `org.openmetronome`, versionCode **22**, Android 8+.

- Poprawiono otwieranie metronomu i statystyk z widgetów, także z pełnego ekranu;
  kolejne żądania są obsługiwane bez restartowania odtwarzania.
- Zachowano edytowany preset po odtworzeniu aktywności; usunięty preset nie
  pozostaje dostępny do edycji.
- Stop anuluje wcześniejszy Start z widgetu oczekujący na wczytanie danych.
- Rozszerzono ciche testy widgetów i kontrole oficjalnej aktualizacji.

Bez zmian silnika PCM, schematu Room, formatu kopii, identyfikatora pakietu
lub klucza podpisu. Odbiór widgetów w launcherze Samsunga, zachowania po zabiciu
procesu oraz odświeżania statystyk po końcowym zapisie pozostaje otwarty.
Fizyczne jitter i latencja nie zostały zmierzone.

Oficjalny podpis, SHA-256 oraz aktualizacje oryginalnych APK 1.2.0 → 1.2.1
na API 26 i 35 przeszły weryfikację. Szczegóły, w tym pierwszy nieudany test
DEV API 26 i udana powtórka: [raport weryfikacji](../V1.2.1-VALIDATION.md).
