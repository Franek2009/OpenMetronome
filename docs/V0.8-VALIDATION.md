# 0.8.0-beta.1 — przygotowanie publikacji

VersionCode 8. Bez zmian silnika audio i schematu danych. Krótszy pasek
nawigacji, dokumentacja publiczna oraz podpisywanie i GitHub Releases.

## Lokalnie — 2026-10-20

- 98 JVM PASS; Lint debug i release: 0 błędów, 0 ostrzeżeń.
- Debug, instrumentacja, niepodpisany i podpisany release: kompilacja PASS.
- Parser instrumentacji: 7 scenariuszy PASS; testy skryptów wydawniczych PASS.
- Actionlint 1.7.12: oba workflow bez błędów; lokalne linki Markdown poprawne.
- Negatywne kontrole: Gradle odrzucił oficjalny build bez zmiennych podpisu;
  pakowanie odrzuciło APK niepodpisany i debug. Test skryptu smoke odrzucił
  numer urządzenia fizycznego przed wykonaniem jakichkolwiek poleceń ADB.
- Podpis wydawniczy APK: v2, RSA 4096, właściwy certyfikat. Brak flagi debug,
  pakiet org.openmetronome, code 8 / 0.8.0-beta.1. Brak uprawnienia INTERNET.

Pierwsza analiza Lint została przerwana po utknięciu w przejściu drzewa PSI
(BidirectionalTextDetector). Powtórzenie na niezmienianym kodzie z dwoma
workerami zakończyło cały build w 2 min 25 s. Nie wyłączano tego detektora.
Ostrzeżenie ConfigurationScreenWidthHeight wyciszono tylko na celowym odczycie
wysokości do klasyfikacji okna: rozmiar treści z klawiaturą nie może zmieniać
wariantu tabletu. Nie służy to obliczaniu rozmiarów elementów w pikselach.
